# 🚗 IR 무선조종 비비탄 사격 자동차 시스템

> AVR ATmega16A 기반으로 설계한 **적외선(IR) 무선조종 비비탄 자동차 프로젝트**  
> 송신기와 수신기를 각각 독립 MCU로 구성하여,  
> **차량 주행 / 카메라 회전 / 전조등 / 발사모드 / 비비탄 사격** 기능을 구현하였습니다.

# 📖 프로젝트 소개

본 작품은 단순한 RC카 제작이 아닌,  
**IR 적외선 통신 프로토콜을 직접 설계한 무선 전술 사격 차량 시스템**입니다.

리모컨 송신부에서 사용자의 버튼 입력 및 조이스틱 입력을 감지하여  
각 동작마다 서로 다른 길이의 적외선 펄스를 송신하고,

자동차 수신부에서는 이를 실시간 카운트하여  
해당 명령으로 해석 후 각 장치를 동작시킵니다.

# 🎮 송신부(Remote Controller) 동작 원리

송신부는 사용자의 입력을 읽어 각 명령을 `mode` 값으로 저장한 뒤,  
Timer Interrupt 내부에서 적외선 LED를 특정 시간동안 HIGH 유지시켜  
명령 신호를 송신합니다.

## 송신부 주요 입력 기능

| 입력 | 기능 |
|------|------|
| 방향 버튼 | 전진 / 후진 / 좌 / 우 |
| 조이스틱 | 차량 이동 제어 |
| joy_sw | 발사 |
| drone 버튼 | 카메라 좌우 회전 |
| safety_key | 안전모드 |
| semiauto_key | 단발모드 |
| brust_key | 점사모드 |
| auto_key | 연사모드 |

---

## 송신부 핵심 코드 : 입력 감지

```c
void key_move(){
    if(joy_y == 1 && mode1_flag == 0){ mode = 1; } // 전진
    if(joy_y == 2 && mode2_flag == 0){ mode = 2; } // 후진
    if(joy_x == 1 && mode3_flag == 0){ mode = 3; } // 좌회전
    if(joy_x == 2 && mode4_flag == 0){ mode = 4; } // 우회전
    if(joy_sw == 0 && mode5_flag == 0){ mode = 5; } // 발사
}
```

사용자가 버튼을 누르면 해당 mode가 활성화됩니다.

---

## 송신부 핵심 코드 : IR 펄스 송신

```c
void ir_sig(){
    if(mode == 1){
        sig_point++;
        if(sig_point == 1) signal = 1;
        if(sig_point == 180) signal = 0;
        if(sig_point >= 200){ sig_point = 0; mode = 0; }
    }
}
```

각 mode마다 서로 다른 HIGH 유지시간을 가지도록 설계하여  
수신부에서 명령을 구분할 수 있도록 만들었습니다.

# 📡 IR 통신 프로토콜 설계

본 프로젝트는 별도의 데이터 패킷이 아닌  
**펄스폭(Pulse Width) 기반 명령 인코딩 통신**을 사용합니다.

| 명령 | 송신 HIGH 유지시간 |
|------|-------------------|
| 전진 | 180 |
| 후진 | 195 |
| 좌회전 | 220 |
| 우회전 | 290 |
| 발사 | 310 |
| 카메라 좌회전 | 330 |
| 카메라 우회전 | 400 |
| 안전모드 | 420 |
| 단발모드 | 440 |
| 점사모드 | 518 |
| 연사모드 | 540 |

즉, 명령마다 HIGH 신호의 길이가 다르며  
수신부는 이를 카운트하여 어떤 명령인지 판단합니다.

# 🚙 수신부(Car Body) 동작 원리

수신부는 IR 센서 입력을 받아 HIGH 구간의 길이를 `number` 변수로 누적합니다.

```c
if(signal == 0 && sig_flag1 == 0){
    sig_flag1 = 1;
    number++;
}
```

이후 `sig_mode()` 함수에서 number 범위를 분석하여  
해당 장치를 동작시킵니다.

---

## 수신 명령 해석 예시

```c
if(number >= 4 && number < 10){
    mode1_cnt++;
}
if(mode1_cnt >= 50){
    mode = 1;   // 전진
}
```

즉 송신부에서 발생한 펄스 길이를  
수신부에서 범위 비교 방식으로 해석하는 구조입니다.

# 🔥 수신부 주요 기능

---

## 1. 차량 주행 제어

- 전진
- 후진
- 좌회전
- 우회전
- 전진좌회전
- 전진우회전
- 후진좌회전
- 후진우회전

```c
if(mode == 1 && mode1 == 0){
    PORTC.2 = 1; PORTC.3 = 0;
    PORTC.4 = 1; PORTC.5 = 0;
}
```

DC모터의 정역 제어를 통해 차체를 이동시킵니다.

---

## 2. 드론 카메라 회전

```c
if(stepmode == 1){
   tick++;
   ...
}
```

스텝모터 여자 순서를 변경하여 카메라를 좌/우 회전시킵니다.

---

## 3. 비비탄 발사 시스템

총기모드는 총 4가지입니다.

| gun_mode | 설명 |
|----------|------|
| 0~1 | 안전/전조등 |
| 3 | 단발 |
| 4 | 점사 |
| 5 | 연사 |

```c
if(gun_mode == 3){
   fire_cnt++;
   if(fire_cnt <= 115) fire = 1;
}
```

타이머 카운트를 이용하여 발사 시간을 정밀하게 제어합니다.

---

## 4. 서보모터 로봇팔 제어

- 손목 회전
- 센서 회전
- 그리퍼 회전

수신 mode 상태에 따라 PWM 형태의 펄스를 출력하여 제어합니다.

---

## 5. FND 디버깅 표시

현재 수신된 IR 신호값을 FND에 출력하여  
디버깅 및 명령 인식 상태를 실시간으로 확인할 수 있습니다.

# ⏱ Timer Interrupt 기반 멀티 제어

본 프로젝트는 `Timer2 Overflow Interrupt`를 중심으로  
모든 장치를 동시에 제어합니다.

```c
interrupt [TIM2_OVF] void timer2_ovf_isr(void){
    step();
    fnd();
    motor();
    gun();
    sig_mode();
    arm();
}
```

이를 통해:

- 모터 제어
- 발사 제어
- 카메라 회전
- FND 출력
- 신호 분석

을 실시간 병렬처리처럼 구현하였습니다.
